# Vendored: Matt Pocock's agent skills

The following 25 skill directories are vendored copies of the published skill set from
[mattpocock/skills](https://github.com/mattpocock/skills) (the `skills` array of
`.claude-plugin/plugin.json`), installed per that repo's "copies editable skill files into
your project" path. Local edits are fair game — that is the point of this install mode.

- **Source commit**: `6654f6b60cd9d5be8b54c6fafe44346dabeb3b76` (plugin version 1.2.3)
- **License**: MIT (Copyright (c) 2026 Matt Pocock) — full text below
- **Vendored skills** (engineering): ask-matt, code-review, codebase-design, diagnosing-bugs,
  domain-modeling, grill-with-docs, implement, improve-codebase-architecture, prototype,
  research, resolving-merge-conflicts, setup-matt-pocock-skills, tdd, to-spec, to-tickets,
  triage, wayfinder, wizard
- **Vendored skills** (productivity): grill-me, grilling, handoff, teach, to-questionnaire,
  wait-what, writing-for-agents
- **Not vendored**: the source repo's `misc/`, `in-progress/`, and `deprecated/` skills
  (not part of the published plugin set).
- **Note**: `code-review` shares its name with Claude Code's built-in `code-review` skill;
  the project-scoped copy and the built-in coexist — remove this directory if the collision
  is a nuisance.
- Repo-specific configuration written by `setup-matt-pocock-skills` lives in
  `docs/agents/` (issue tracker, triage labels, domain-doc layout).

The `spectrafilm-dev`, `spectrafilm-solutions`, and `brutalist-re` skills are NOT part of
this vendored set.
